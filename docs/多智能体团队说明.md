# 短视频复刻多智能体团队

本项目使用稳定的英文 `id` 连接代码和工作流，界面、日志和交付文档使用中文 `display_name`。角色定义的机器可读版本位于 `config/video-replication-agents.zh-CN.json`。

## 角色表

| ID | 中文名称 | 主要产物 |
| --- | --- | --- |
| `workflow_orchestrator` | 总导演 | 项目状态与交接清单 |
| `video_analyzer` | 视频拆解师 | `analysis/evidence.json`、镜头和本地帧 |
| `shot_planner` | 复刻策划师 | `analysis/plan.json` |
| `keyframe_curator` | 关键帧拼图师 | 连续编号的 `shot-sheet-*.jpg` 与 `manifest.json` |
| `prompt_director` | 提示词导演 | `outputs/prompts.json`、最终提示词 |
| `quality_reviewer` | 质量验收官 | `outputs/review-context.json`、绑定产物哈希的 `outputs/scope-approval.json`、`outputs/qa.json` |
| `provider_adapter` | 生成执行师 | 脱敏请求、状态和生成视频 |
| `delivery_packager` | 交付打包师 | ZIP 素材包和中文教程 |

## 标准交接

1. **总导演**初始化项目并登记输入路径。
2. **视频拆解师**只在本地读取原视频，输出镜头证据、音频信息和本地帧。
3. **复刻策划师**与**关键帧拼图师**可以并行工作。关键帧默认按时间每秒一帧，每三张连续帧合成一张横向拼图，编号从 `Shot 01` 全局递增。
4. **提示词导演**合并镜头计划、三联图和产品参考图，写清“保留人物，只替换产品”。
5. **质量验收官**在生成前检查时长、画幅、素材数量、连续性和人工审核项。
6. **生成执行师**默认只做检查、计划、计价或 dry-run；只有费用审批通过后才提交真实任务。
7. **交付打包师**同时交付两条路径：直接生成的成片，或可上传到其他平台的素材包和教程。

## 审批规则

- `reference_scope`：确认复刻范围、产品替换范围和是否允许使用原视频。
- `generation_billing`：确认第三方模型、时长、分辨率和可能产生的费用；没有确认时不得执行付费 Build。
- `delivery_release`：确认 ZIP 不含密钥，且教程、提示词、参数和音频说明齐全。

## 给同事的最小用法

先查看配置：

```powershell
Get-Content .\config\video-replication-agents.zh-CN.json
```

再按项目 README 的命令执行 `analyze`、`plan`、`prompts`、`keyframes` 和 `qa`。任何角色失败时，只重跑该角色及其下游，不删除上游 artifacts。

## 隐私边界

原始视频和本地帧默认只在本机处理。交给第三方生成 API 的应是已审核的提示词和公网可访问的参考图 URL；日志与请求文件必须脱敏，不能包含 API token。
