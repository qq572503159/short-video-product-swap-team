# 生成与交付

## Provider 选择

- Hypit 的 Model、Provider 和 Endpoint 是不同层。相同模型名不代表第三方 API 协议兼容。
- 当前项目的 Hypit capability `@hypit/seedance@1#seedance-2-mini` 可由项目 Provider 映射到 New API 的 `seedance-2.0-mini`。
- Python 直连 `minimax-h3-f` 是另一条链路，不应只修改显示名称后冒充 Hypit capability。
- 第三方接口需要公网素材 URL 时，只公开三联图和产品图，不公开原视频。

## 费用门禁

提交前展示可确认的信息：模型、时长、分辨率、请求数、第三方定价入口或已知历史实际费用。只有用户明确确认后才使用 `--submit --confirm-billing` 或 Hypit `build`。

连接验证使用 `doctor`、`check`、`plan`、`pricing` 或 dry-run，不用付费生成任务探活。

## 逐镜结构门禁

- API 请求提示词必须由审核通过的 `replication-framework.json` 与改写后的 `script-timeline.json` 编译，不得仅凭拼图和一句全局描述直接提交。
- 每镜至少写明原片时间范围、场景、景别/构图、动作过程、机位/运镜、镜头连续性；原片真实剪辑点必须保留。
- 产品替换限定在原有产品位置与呈现方式；文案替换限定在相应时间轴对白字段。不得因新产品或新文案重构镜头。
- 有占位字段、缺失镜头、时间重叠或文案时段超出成片长度时，阻止提交并回到拆解补全。
- 关键帧中烧录字幕、价格、贴纸应声明为需清除的覆盖层；不能把它们作为文字复刻目标。
- 按用户音频要求选择 `silent`、`ambient`、`voiceover` 或 `full`。用户要求口播时，逐段传入改写文案并明确同步生成语音，不能沿用静音模板。

## 手动平台包

教程应覆盖：上传顺序、平台图片数量上限的降级组合、画幅与时长、关闭生成音频、低创意度、参考强度、候选成片检查和本地接回原音轨。平台只支持单图时，分别生成短片再剪辑，不把三联图当成最终布局。

## 成片验收

至少检查：人物身份、发型服装、机位场景、产品位置、产品标签稳定性、动作连续性、字幕、水印、音轨、分辨率和时长。将通过、有限通过和未通过逐项写入报告。
