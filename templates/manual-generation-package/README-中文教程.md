# 短视频复刻手动生成教程

本素材包适用于支持“多图参考生视频”或“参考图生视频”的平台。原始参考视频不需要上传。

1. 按文件名顺序上传 `01-upload-assets/shot-sheet-*.jpg`；每张图内的 `Shot` 编号是全局连续的时间顺序，不是每张图重新从 1 开始。
2. 再上传 `01-upload-assets/` 内的产品参考图（本项目为宴友大曲碎沙标准样黑瓶产品图）。
3. 粘贴 `02-generation-prompt.txt`，参数参考 `03-parameters.json`。
4. 选择竖屏 9:16、目标时长、720p 或更高，关闭生成音频，使用中高参考强度和低到中创意度。
5. 下载人物最稳定、产品最接近参考图的一版，命名为 `generated-silent.mp4`。当前方案要求生成无声视频，不要把参考视频原音直接合回去。
6. 根据 `script-timeline.json` 和 `adapted_script.md`，用你选择的 TTS 或真人配音生成新的音频；严格按时间轴使用“改写文案”字段，T08 不重复配音。
7. 将新配音与 `generated-silent.mp4` 合成最终视频。`merge-original-audio.ps1` 仅适用于明确选择 `original_audio` 的旧流程，本项目当前不要使用。

本项目支持两种拼图密度：默认每张 3 帧；也可使用每张 6 帧（3 列 × 2 行）。无论哪种密度，`Shot` 编号都从全局 1 开始连续递增。若平台图片数量有限：优先按文件名顺序上传首段、中段、尾段拼图，再上传产品图；允许更多时全部上传。拼图编号只表示时间顺序，最终必须生成连续单画面，不能生成三分屏、六格布局、编号、边框、字幕或水印。
